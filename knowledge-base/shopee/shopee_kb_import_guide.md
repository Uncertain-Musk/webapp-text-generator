统一导入文件为 UTF-8-SIG，只包含 question、answer，顺序固定，共 97 条；内容按原广告 20、行业研究 8、新增多站点 69 条合并，问答正文、来源与核验日期保持不变。三份原始 QA 为独立维护文件，使用合并版时不同时导入它们，避免重复。

Question = 索引 0；Answer = 索引 1。导入文件不得增加来源、分类、站点或 ID 列。管理表中的 market 不表示 Workflow 已实现 metadata filtering。

## 人工操作

1. 先运行下面的检查，复核来源表的站点、对象、页面日期、核验时间与限制。优先审核高风险售后期限、旧日期页面和未解决 Gap；不能只更新核验日期。
2. 在非生产测试知识库中，使用支持已有 QA CSV 的导入入口；按当前 Dify 版本的 QA 模板确认第一列为 Question、第二列为 Answer。不要让 LLM 重写或自动生成现成 QA。
3. 选择 `shopee_all_qa.csv`，预览首、中、末行，以及第 20/21、28/29 条分类边界，确认完整问题、答案和来源没有拆列、错位或截断。若当前版本不提供双列 QA 导入，停止并查对应版本官方模板；本轮未核验控制台版本，不臆测按钮名称。
4. 有效条目共 97。每个市场抽查实际 Question/Answer，并检查跨站点多来源答案没有截断。原三份 QA 不与合并版同时导入；已有这些条目的目标库须先确认重复文档处理方案。来源、覆盖、Gap、测试、研究文件及指南均不导入。
5. 在测试库先执行下列原广告冒烟，再按新固定 82 条测试核验实际召回及回答。保存命中问题、完整答案、来源、上下文和判定，不用关键词命中替代事实判断。现有网页 Shopee 选择器只有 SG/MY/PH；其他站点用问题中的明确市场提问，新测试集的这些 market_context 为空，不要求改网页选项。
6. 生产导入、检索节点的数据集选择与上线由负责人审核后手动进行。保留原有 General/Policy；本轮不改 Prompt、模型或 Workflow。测试库通过不等于生产回答质量已通过。

## 自动检查

```powershell
python script/validate-shopee-kb.py
python script/test-shopee-kb.py
python script/validate-shopee-multimarket.py --report knowledge-base/reports/shopee-multimarket-validation-2026-10-11.json
python script/test-shopee-multimarket.py
```

检查严格 UTF-8 解码、两列及顺序、空值、重复、映射孤儿、允许来源域名、日期、站点一致性，以及人工指定的问答主题词。负例覆盖列错位、额外列、坏编码、空答案、重复、丢失映射、同源答案交换和跨站混用。

多站点检查还验证各题所需的全部来源、来源站点和适用对象、已审查问答的内容哈希、覆盖数与 Gap 对照、不可伪造 COMPLETE 和真实 Dify 测试结果。证据与逐题定位保存在研究 JSON 及来源表；完整官方正文仅作临时阅读，不复制进仓库。

这些是结构与一致性防线，不是自动事实鉴定。导入前仍须复核规则更新。没有使用外部 LLM 做校验。`python script/build-shopee-multimarket.py` 可从已审查研究 JSON 重建五份多站点 CSV，既不修改旧文件，也不刷新来源核验日期；公开页面研究脚本只用于取得待审正文，不自动更新事实。维护文件变化后须重新生成合并版，并重新检查 97 条问答的完整一致性；原校验器只检查各自维护文件。

## 原广告与行业研究来源限制（2026-10-10）

- Shopee 中文指南不标注具体适用站点，仅保留基础流程、出价和收费定义；未将其变成所有站点规则。
- 新加坡官方页面已阅读全文。部分旧搜索广告功能仅对部分卖家开放。创建页面与优化页面关于 Enhanced Bid Price 最大上调幅度存在 100% / 50% 差异，争议数值未写入 QA。
- Paid Sales 页面 Q1 明确后续取消/退货仍计入，Q3 的概括表述容易误读；候选保留 Q1 的明确限定，不声称已剔除退款。
- Momentum Works 指定文章复取超时；使用同机构公开的 2026-04-14 新闻稿（来源 MW，第 1–2 页），报告统计年份为 2025。文件名含 Embargo，但当前日期已晚于其公开日期；只使用公开内容。未获取付费报告完整方法，不把摘要当作全文。
- e-Conomy SEA 首页成功访问，2025 完整报告下载失败；使用 Google 联合发布方 2025-11-11 公开摘要及脚注，不补造全文内容。
- ChannelEngine 原始 PDF 链接复取超时，同站点带 hsLang=nl 参数的 PDF 成功取得 20 页英文全文；样本说明见第 2 页、手工工时见第 9 页。2025 是历史报告，不能称为最新报告；2026 版已存在但不混入本批统计。
- CPC、CPM 的单位换算、零分母和保本公式是明确标注的数学推导，不是新增平台收费规则或行业阈值。没有将报告相关性当成商家高频提问证据。

## 撤回与更新

本地文件不影响生产。人工导入后如有问题，按对应文档禁用或撤回本批新增 QA，保留原知识库；更新规则时同步修改答案、来源表和语义检查项，再重新验证。不得只更改核验日期而不重新访问来源。
