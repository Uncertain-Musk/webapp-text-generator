## 审计与边界

Next.js 15.5.25 App Router、React 18.3.1、TypeScript 5.9.3；全局 CSS/Tailwind 3 与既有越海绿色视觉。复用 SiteShell，保留全部导航；经营工具入口为 /tools，新页 /tools/shopee-ads。没有新增依赖。

已查看 [Recharts 项目](https://github.com/recharts/recharts) 的 React/D3 实现与 MIT 许可证。成熟图表库适合复杂坐标图，本页只有三个非独立用户的归因阶段，使用原生有序列表与 CSS 即可；没有复制第三方源码或增加依赖，避免额外供应链和适配成本。采用 SVG 三段数据驱动漏斗；上沿宽度按数量平方根缩放，明确声明面积不代表数量。

原问答为独立 query 与 platform_context/market_context，经本站服务端代理传入 Dify。新工具只持有组件状态，不调用 API、Dify 或模型，不接入真实广告账户；刷新清空，不写 localStorage。顶部经营环境仍服务于知识问答，新工具选择独立。

本次开始时仓库已有未提交的 Streaming 部分回答保留、服务错误处理、诊断 Route/CLI/测试以及文档改动。生产约 31 秒 EOF 的根因与修复仍未确认；本版本不覆盖这些改动、不声称解决生产断流。原 General 500 条和 Policy 124 条 CSV 保留；历史政策质量 FAIL 也未被本版本修复。

## 输入与公式

同一统计周期、币种、归因窗口、商品范围、订单与销售状态是使用前提。币种显式展示，不自动换汇；站点不约束报表可能使用的记账币种。金额为非负有限十进制，计数为非负安全整数，数值不得超过 JavaScript 安全整数上限。负数、非数字、无限值、计数小数、反向日期和点击超过曝光阻止诊断；空值不当作零。

| 指标 | 公式 |
| --- | --- |
| CTR | 点击 / 曝光 × 100% |
| CPC | 广告花费 / 点击 |
| CPM | 广告花费 / 曝光 × 1000（等效成本，不表示收费方式） |
| ROAS | 归因销售额 / 广告花费 |
| ACOS | 广告花费 / 归因销售额 × 100% |
| 每订单广告成本 | 广告花费 / 归因订单 |
| 订单点击比 | 归因订单 / 点击 × 100% |
| CVR | 已提供的 Conversions / 点击 × 100%，不以订单替代 |
| 估算保本 ROAS | 1 / 广告前贡献毛利率的小数形式 |

分母为零或缺少必要数据用“—”及原因展示，不输出 Infinity/NaN；不会用 LLM 修正计算结果。贡献毛利率须在 (0,100] 且明确确认成本范围。该估算未包含固定成本与增量归因判断，Paid 销售也不自动等于退款后的净收入。

订单大于点击是口径警告：点击归因提示核查跨商品/重复购买/窗口；浏览或混合归因提示未点击订单，不当作数学错误。漏斗使用平方根宽度缩放并保留真实数量与比率，归因比率不是独立用户转化率。

## 诊断规则

优先级依次为：输入修复、归因核对、低于估算保本线、无点击/无订单、低于自设目标、达标测试、数据不足、建立自身比较基准。每条均有发现、可能原因与下一步。

多个问题可同时展示。低于保本线或存在口径警告时，不同时建议达标扩量。没有自设目标不做“达标/未达标”判断；缺少 Conversions 不产生 CVR。零分母或尚无订单提示数据不足，非零数据也不宣称统计充分；不引入固定行业阈值。

## 分层经营建议

漏斗每层右侧对应数据发现、判断边界、可展开的三步执行计划与复查指标，并提供官方依据。每段上沿宽度 = sqrt(该阶段数量 / 三阶段最大值) × 100%；下沿取下一阶段宽度，末段收尖。零数量不绘制色块，无效输入显示等待数据。订单超过点击时允许扩宽，不伪造递减。非线性缩放有明确图注，面积不表示数量。采用一张连续 SVG，文字全部放在右侧白底建议区；每行开头显示阶段名、完整数量和真实比率。ResizeObserver 观察三条建议行的实际高度，将同一组边界坐标用于 SVG 分层；展开、收起、换行和屏幕尺寸变化时同步更新，避免三张独立图造成间隙。手机收窄图形列并保留右侧完整文字，卸载时断开观察器。

广告类型可选手动商品搜索广告、GMV Max 或暂不确定。手动广告才提供关键词/匹配方式操作；GMV Max 提醒学习期稳定与目标核对。达标时保留有效商品和设置，检查库存、履约、退款与商品结构，隔离新测试预算；不因单期达标承诺可持续盈利。输入异常、口径风险、保本线优先于扩量建议，没有目标不判定达标，没有历史不判定 CTR 高低。

在归因一致且无口径警告时，使用目标 ROAS 与可用保本 ROAS 中较高者 R，推导每订单成本参考 = 当前客单价 / R；点击归因还可推导 CPC 参考 = 当前销售额 / 点击 / R。这是保持当前销售结构的静态核算，绝非平台出价上限或未来效果预测。摘要复制包含三层完整计划、复查指标和来源。

官方原则于 2026-10-10 实际核验，适用于新加坡站；其他站点需核对本地后台。来源定义在 utils/shopee-ads.ts 的 adviceSources：

- [搜索广告优化](https://ads.shopee.sg/learn/faq/526/180)：按目标检查商品与关键词表现，核对商品页和价格；部分卖家适用。
- [选品与匹配](https://ads.shopee.sg/learn/faq/526/187)：选品对应经营目标，匹配方式覆盖范围不同。
- [GMV Max](https://ads.shopee.sg/learn/faq/519/1787)：参考历史设置目标，学习期避免无必要修改，目标不保证达成。
- [销售额口径](https://ads.shopee.sg/learn/faq/525/2147)：Placed 与 Paid 不可混用，Paid 不自动排除后续取消/退款。

页面明确区分官方原则与本工具依据输入制定的核查计划；可能原因不是已证实因果。不添加无来源的统一 CTR、预算增幅或学习天数阈值。

## 达标诊断的执行清单

“04 诊断与下一步”的达标结论展示实际 ROAS、自设目标、相对差距、花费、订单、销售及可用保本线。固定展开四步：核对订单质量和集中度；保留有效商品设置；单变量测试并由商家设定花费上限/结束日期；在完整归因后按目标与保本线较高者复查。缺货、履约异常或触及商家自定花费上限可提前停止测试。静态总花费参考不代表新增预算。毛利率缺失不推断盈利，GMV Max 单独提示学习期。复制摘要包含完整执行清单。
